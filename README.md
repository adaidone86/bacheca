# Bacheca

Una bacheca semplice e minimalista per condividere contenuti, progetti o annunci.

## Caratteristiche

- 📱 Responsive design
- ✨ Interfaccia moderna e pulita
- 🚀 Pronto per GitHub Pages
- ⚡ Nessuna dipendenza esterna

## Come usarla

1. Clona il repository
2. Personalizza `index.html` con i tuoi contenuti
3. Pubblica su GitHub Pages
